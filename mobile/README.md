# App Mobile (React Native + Expo)

Estrutura sugerida para 4 apps por perfil com navegação compartilhada:
- `apps/client`
- `apps/store`
- `apps/courier`
- `apps/admin`

Inclui:
- autenticação JWT com refresh
- mapas premium (react-native-maps + animação)
- websocket para rastreio
- push FCM
- cache e paginação

> Para acelerar, iniciar com Expo Router e monorepo Turbo/Nx.
